The Morphir CLI is built and released from the
[finos/morphir](https://github.com/finos/morphir) repository. See
[Installing Morphir](https://github.com/finos/morphir/blob/main/INSTALLING.md)
for current installation instructions, and the
[CLI Reference](https://morphir.finos.org/docs/cli/) for command
documentation.
