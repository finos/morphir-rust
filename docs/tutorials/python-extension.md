# Python ADT extension

The Python extension (crate `morphir-python-binding`, bundle `morphir-python`) is
now maintained and released from
[finos/morphir-python](https://github.com/finos/morphir-python). Its source,
tests, examples and release bundles live in that repository. This repository no
longer builds or releases it.

The historical `extension/python/v0.1.0` to `extension/python/v0.4.0` bundles
remain available in the
[morphir-rust releases](https://github.com/finos/morphir-rust/releases).
